클로드 코드와 함께 블로그를 만들면서, HTML·CSS·JavaScript가 각각 어떤 역할을 맡는지 다시 한번 정리해봤다.

## HTML — 구조와 뼈대

`index.html`과 `post.html`은 페이지의 뼈대만 담당한다. 글 목록이 들어갈 자리(`<ul id="post-list">`), 글 본문이 들어갈 자리(`<div id="post-root">`)처럼 **빈 껍데기**를 잡아두고, 실제 내용은 JavaScript가 채워 넣는 구조다. 콘텐츠 자체(마크다운 파일)와 화면의 틀(HTML)이 분리되어 있는 게 핵심이었다.

## CSS — 테마와 반응형

색상, 여백, 폰트 같은 값을 `:root`에 변수로 모아두니 라이트/다크 테마 전환이 훨씬 쉬워졌다.

```css
:root {
  --color-bg: #ffffff;
  --color-text: #1c1c1c;
}
:root[data-theme="dark"] {
  --color-bg: #16161a;
  --color-text: #e7e7e5;
}
```

`prefers-color-scheme` 미디어 쿼리로 시스템 설정을 기본값으로 따르고, 미디어 쿼리 하나로 좁은 화면에서 폰트 크기와 여백을 줄여 모바일 대응까지 처리할 수 있었다.

## JavaScript — 동작과 데이터 연결

세 가지 역할로 나뉘었다.

1. **파싱**: `markdown.js`가 마크다운 텍스트를 정규식으로 한 줄씩 분석해 HTML 문자열로 바꾼다.
2. **데이터 연결**: `home.js`와 `post.js`가 `fetch`로 `.md` 파일을 읽어와 파서에 넘기고, 결과를 화면에 삽입한다.
3. **상태 저장**: `theme.js`가 다크모드 선택값을 `localStorage`에 저장해 새로고침해도 유지되게 한다.

프레임워크 없이도 "데이터를 가져온다 → 변환한다 → 화면에 그린다"라는 흐름만 명확히 나누면 충분히 동작하는 사이트를 만들 수 있다는 걸 배웠다.
